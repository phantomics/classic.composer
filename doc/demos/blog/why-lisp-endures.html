Homoiconicity

Lisp's code-as-data property means the language can transform itself . Macros are not text substitution -- they are programs that write programs, operating on the same data structures the runtime uses.

CLOS

The Common Lisp Object System provides multiple dispatch , method combination, and a metaobject protocol that lets you redefine the rules of object orientation itself.

The Condition System

Unlike exception systems that unwind the stack, Common Lisp's condition system lets the caller decide how to handle errors without destroying the context where the error occurred.
